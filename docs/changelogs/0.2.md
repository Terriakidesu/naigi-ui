# 0.2.x

## 0.2.3 — 2026-10-01

### Fixed

- Replaced font-based UI symbols with SVG icons in theme previews, close buttons, attachments, media playback, external-link dialogs, and space-management controls.
- Render dynamically created Lucide icons immediately, without waiting for a page-wide icon conversion.
- Removed font-dependent symbols from role expand/collapse and submenu indicators.

## 0.2.2 — 2026-10-01

### Changed

- Grouped frontend TypeScript, HTML pages, public assets, and styles into dedicated source directories without changing bundled output paths.

## 0.2.1 — 2026-10-01

### Changed

- Simplified the README into a quick-start and documentation index.
- Added dedicated usage, development/packaging, and security guides, including current release and test limitations.

## 0.2.0

Release date: 2026-10-01.

### Added

- The user-facing Naigi chat frontend is bundled with the desktop app and builds with Node.js/npm; the [server's admin console](https://github.com/Terriakidesu/naigi) is not included.
- A secure local app origin bridges the bundled frontend to the selected server's `/v1` HTTP API and authenticated realtime WebSocket.
- The server chooser checks connectivity and displays the server version separately from the desktop app version; both versions remain visible in chat and in **Help → About Naigi**.
- Release targets include Linux AppImage/deb packages and Windows NSIS installer/ZIP packages.
- Version-scoped changelogs under `docs/changelogs/`.

### Security

- The desktop frontend keeps sandboxing, context isolation, and web security enabled. Main-process API proxying is restricted to the validated server origin, and TLS certificate verification remains enabled.
