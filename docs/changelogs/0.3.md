# 0.3.x

## 0.3.0 — 2026-10-01

### Added

- Saved servers in the launcher with one-click connect, most-recent-first ordering, and shortcut removal; existing saved addresses migrate automatically.
- A root MIT license for Naigi Desktop, included in packaged builds.
- Desktop About settings with version information and bundled project, Twemoji, and third-party license notices.
- Custom desktop title-bar navigation and a local development launcher accepting an explicitly configured CA certificate.

### Fixed

- Ask before moving a voice-room connection from another device to this desktop. Cancelling preserves the other connection; a transferred-away desktop does not automatically rejoin.
- Preserve the replacement device in the voice roster when the previous device's departure arrives late.
- Forward selected-server session cookies through HTTP and realtime proxies without mixing origins.
- Give recovery unlock an explicit form, progress and error states, and deduplicated pending attempts.
- Keep conversation search aligned with chat actions and close the manual recovery backup section correctly.
