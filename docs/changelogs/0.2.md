# 0.2.x

Release date: 2026-10-01.

### Added

- The user-facing Naigi chat frontend is bundled with the desktop app and builds with Node.js/npm; the server's admin console is not included.
- A secure local app origin bridges the bundled frontend to the selected server's `/v1` HTTP API and authenticated realtime WebSocket.
- The server chooser checks connectivity and displays the server version separately from the desktop app version; both versions remain visible in chat and in **Help → About Naigi**.
- Version-scoped changelogs under `docs/changelogs/`.

### Security

- The desktop frontend keeps sandboxing, context isolation, and web security enabled. Main-process API proxying is restricted to the validated server origin, and TLS certificate verification remains enabled.
